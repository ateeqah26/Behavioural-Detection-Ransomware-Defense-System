How it works

Three stages, no kernel driver required.

stage 1

Monitor

Canary files sit untouched in protected folders. Watchdog watches every folder for file events in real time.

stage 2

Verify

Entropy analysis, extension checks and burst-rate detection confirm the activity actually looks like encryption, not a normal edit.

stage 3

Alert

The file, process (if identifiable) and timestamp are logged and pushed to this dashboard live — instantly, no popup needed.
